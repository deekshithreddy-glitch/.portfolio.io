Preview:
- Open index.html in a web browser.

Publish free with GitHub Pages:
1. Sign in to GitHub and create a new public repository named: deekshithreddy-glitch.github.io
2. Upload index.html and the entire assets folder (keep the profile photo inside assets).
3. In the repository, open Settings → Pages.
4. Under Build and deployment, choose Deploy from a branch, select main and /(root), then Save.
5. After GitHub Pages finishes publishing, your website should be available at:
   https://deekshithreddy-glitch.github.io/

You can edit index.html any time to update your details. Do not rename or move assets/profile-photo.png unless you also update its path in index.html.
